REGLA MERCADOLIBRE
El número de venta se registra con su formato de 16 dígitos, por ejemplo 2000018505705824. Una misma venta + producto devuelve siempre el mismo código y no genera duplicados. Antes de activarse, el código no contiene email del comprador. Cuando el cliente verifica su correo y activa el código, la licencia queda asociada definitivamente a esa cuenta, comienza la vigencia configurada para ese código y se habilita el límite de dispositivos.
